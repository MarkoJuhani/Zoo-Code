## Exceptional entry and exact target

Prove **separately** that the predecessor's actual process exited, that every in-flight same-parent operation was drained or cancelled (including asynchronous saves, prepared child and pending schedule), and that no other capable host can write/start. A vanished socket, queue count, bundle on disk, or process-local transition mutex proves none of those facts ([entry policy](../../../../.roo/interrupted-create-handoff-manual-supersede-proposal.md:9), [local transition](../../src/core/webview/ClineProvider.ts:292), [prepared child and commit](../../src/core/webview/ClineProvider.ts:4059), [schedule](../../src/core/webview/ClineProvider.ts:4159)). Before **targeted** startup replay, hydration or scheduling, verify the restarted **LOADED** build identity and actual host instance, canonical real storage root, exact parent identity and complete saved action; missing or uncertain proof blocks B ([R1 guard](interrupted-create-handoff-manual-supersede-r1-decision.md:21), [startup order](../../src/core/task-persistence/TaskHistoryStore.ts:118), [saved action](../../src/core/tools/NewTaskTool.ts:105)). No blanket cross-host service is required **only if** predecessor exit/drain and the one-capable-restarted-host boundary are demonstrated; otherwise B remains blocked and A/I0 alone are retained ([operator scope](../../../../.roo/interrupted-create-handoff-manual-supersede-proposal.md:36)).

**Required evidence method, not an existing runtime facility:** capture the predecessor's OS process identity (including start identity), confirm its actual exit, and obtain a shutdown/drain accounting of all accepted same-parent asynchronous writes, prepared children and pending starts; cancel and account for outstanding work before restart. If abrupt termination makes drain accounting impossible, establish that no surviving process/external executor can complete those operations and inspect ambiguous persisted child/intent evidence; otherwise block. From the **running restarted host**, obtain its actual process identity and loaded extension build identifier/hash, not merely the bundle on disk; resolve its task-storage base to a canonical real path, then bind that root to the strict parent/root metadata and the exact parent API file path/full saved action before allowing targeted startup effects. Missing host instrumentation, unresolved root alias, detached worker or second capable host means **BLOCKED**, not operator-attested safety ([startup and writer inventory](interrupted-create-handoff-manual-supersede-r1-decision.md:14), [strict-read limitations](interrupted-create-handoff-manual-supersede-i0-implementation.md:20)).

Before readiness, strictly inspect the canonical parent/root/full old action and status/lineage, raw **and provider-effective** terminal call/result (including order, input, siblings, duplicate/orphan/later turns), known child metadata/registry/intent, pending question and any surviving equivalent same-parent queue request. Resolve an equivalent queued item via ordinary controls **before** ready or separate new intake; B never adopts, claims or deletes it. If inspection, attribution or ordinary resolution cannot be demonstrated, block readiness; no live inspection is claimed here ([B comparison](interrupted-create-handoff-manual-supersede-b1-b2-design.md:15), [queue policy](../../../../.roo/interrupted-create-handoff-manual-supersede-proposal.md:9), [raw-only I0](interrupted-create-handoff-manual-supersede-i0-implementation.md:16)).
