## Implemented boundary and lock order

- The opt-in [binding](../../src/core/task-persistence/targetPersistenceBoundary.ts:72) records a canonical real storage root, exact parent, full persisted action and ownership/question fields, and an ordinary API snapshot independently from later writer arguments. The [fence](../../src/core/task-persistence/parentHandoffFence.ts:68) uses the real root and checks owner **and** generation. Binding is not a B1 eligibility or host-drain token.
- The [entry guard](../../src/core/task-persistence/targetPersistenceBoundary.ts:123) acquires parent exclusion before the store mutex or file lock; [final-file predicates](../../src/core/task-persistence/targetPersistenceBoundary.ts:151) reject absent/lost ownership, changed binding or disk identity. A store-mutex callback cannot acquire a missing parent exclusion. Target failure is scoped; unrelated parents and ordinary questions continue.
- The [API writer](../../src/core/task-persistence/apiMessages.ts:157) checks the bound snapshot under its ordinary file lock, including saves queued before binding. [Legacy migration](../../src/core/task-persistence/apiMessages.ts:127) refuses a bound target rather than promoting an uncertain old file. The bound target cannot gain a changed ordinary API replacement through this path.
- [Upsert](../../src/core/task-persistence/TaskHistoryStore.ts:214), [question update](../../src/core/task-persistence/TaskHistoryStore.ts:1040) and [paired updates](../../src/core/task-persistence/TaskHistoryStore.ts:1100) join exclusion before the store mutex; target output and disk comparisons reject changed full action, owner or question under the task-file lock. A target side of a pair is prevalidated before the first file effect, but the general pair remains nontransactional.
- [Single and batch deletion](../../src/core/task-persistence/TaskHistoryStore.ts:294) check for a bound target before removal and again under the task file's advisory lock; unbound missing-file deletion remains best-effort. [Internal startup file writes](../../src/core/task-persistence/TaskHistoryStore.ts:871) fail closed for a bound target without acquiring parent exclusion inside the store mutex. This does **not** install an early startup quarantine.
